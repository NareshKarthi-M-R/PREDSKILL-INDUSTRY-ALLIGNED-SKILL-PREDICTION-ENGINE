# PredSkill – Industry-Aligned Skill Evolution Prediction Engine  

## Overview  
PredSkill is an AI-powered career guidance system that analyzes user skills, predicts suitable career roles, and generates structured learning roadmaps. The system focuses on bridging the gap between academic learning and real-world industry requirements through data-driven insights.

---

## Key Features  
- Career role prediction based on user skills  
- Skill gap analysis aligned with industry datasets  
- Personalized learning roadmap generation  
- Confidence scoring for career readiness  
- AI assistant (Preddy) for adaptive guidance  
- Real-time technology news integration using GNews API  
- Secure user authentication and progress tracking  

---

## Tech Stack  

### Frontend  
- React.js  
- Framer Motion  
- Recharts  

### Backend  
- Flask (Python)  

### Machine Learning  
- TF-IDF Vectorization  
- Logistic Regression  

### Database & Authentication  
- Firebase  

---

## System Workflow  
1. User inputs skills and domain  
2. Text preprocessing and vectorization (TF-IDF)  
3. Domain and career prediction (Logistic Regression)  
4. Skill gap analysis using dataset mapping  
5. Roadmap generation and confidence scoring  

---

## Dataset  
- Custom dataset (`skill_grow.csv`)  
- Contains job roles and associated skills  
- Used for training prediction models and skill mapping  

---

## AI Assistant – Preddy  
Preddy enhances the system by:  
- Providing interactive assistance  
- Fetching latest technology updates  
- Improving recommendations based on current trends
